# Icon

A line icon from the house set, drawn on a 24px grid with a 1.6px stroke, square ends and mitred corners.

- `name` is one of `JR.Icon.names` (39 icons: facts such as bed, bath, garage, pool, gate; actions such as search, filter, heart, share; portal icons such as pipeline, inbox, activity, bell).
- `size` in px (default 20). Colour comes from `currentColor`.
- Pass `label` only when the icon stands alone; otherwise it is decorative and hidden from assistive tech. Icons always sit beside a word or value.
