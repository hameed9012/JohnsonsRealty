# DocumentHeader

The header band on every printed form and agreement: green band with the lockup and contact lines, then the title, subtitle and form number.

- `title` in `doc-title`; `subtitle` names the parties or the property; `formNo` is the form's ID (like Form JR-PA-100).
- `contact` is a list of `{label, value}` for the band, from brokerage settings.
- `subline` replaces "Brokerage · Pennsylvania" in the band.
