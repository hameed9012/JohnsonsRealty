# Logos

The mark and avatars. `jr-mark-on-light.svg` has a green-900 (#16302a) roof for paper grounds; `jr-mark-on-dark.svg` sits on its own green-900 square with a cream roof. Frame and key are brass-500 (#b4925a) in both.

The PNG avatars are square social images for Chirper, Discord and the in-game business: green ground, cream ground, and the wordmark version. In product UI use the Logo component instead of these files.
